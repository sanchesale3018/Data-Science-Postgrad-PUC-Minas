# 📊 Projeto: União e Integração de Bases de Dados no Power BI

## 🎓 Contexto Acadêmico
Este laboratório prático faz parte da disciplina de **Data Discovery e Analytics** da pós-graduação em Ciência de Dados e Big Data da PUC Minas[cite: 1, 12]. O projeto documenta a reprodução de exercícios voltados para a consolidação de informações de diferentes origens.

## 🎯 Visão Geral e Objetivo
O objetivo central deste estudo é demonstrar a capacidade de trabalhar com múltiplos arquivos e bases de dados distintas simultaneamente dentro do Power BI. O projeto foca na ingestão, cruzamento e união (mesclagem) dessas bases fragmentadas para construir um modelo de dados unificado, fundamental para a estruturação de relatórios e rotinas de *Self-Service Analytics*[cite: 12].

## 🛠️ Ferramentas e Técnicas Aplicadas
* **Power BI (Power Query):** Ingestão de arquivos variados, transformação de dados e consolidação de consultas (Merge/Append).
* **Engenharia de Dados:** Tratamento e integração de bases diferentes para alimentar um modelo analítico coeso.
